# TDX PvP Draft

Сайт для совместного драфта колод Tower Defense X (режим Wheel Draft). Два игрока с разных компьютеров,
синхронизация через бесплатный Firebase Realtime Database, хостинг на GitHub Pages.

## Проверка на своём компьютере (без интернета и Firebase)
Просто откройте `index.html` двойным кликом (или `http://localhost:8000` после `python -m http.server 8000`).
Локальный режим включается сам: состояние хранится в браузере, Firebase не нужен. В шапке будет пометка «ЛОКАЛЬНЫЙ РЕЖИМ».
- **Одному:** в одной вкладке нажмите «Занять Blue», затем «Занять Red». Переключайтесь между командами кнопкой «Играть за …» на нужной половине.
- **Вдвоём на одном ПК:** откройте вторую вкладку и займите другую команду.
- Занятое «зависшее» место можно забрать кнопкой «Перехватить», а одну команду освободить кнопкой «Освободить».
- Принудительно локальный режим: добавьте к адресу `?local`. Подключиться к настоящему Firebase с localhost: `?online`.
На GitHub Pages всегда работает Firebase (игра с разных компьютеров).

## Запуск на GitHub Pages
1. Загрузите все файлы из этой папки в корень репозитория `Bogdan-Ob/tdx-draft-2` (ветка `main`).
2. Repository → Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется на `https://bogdan-ob.github.io/tdx-draft-2/`.

## Firebase (один раз)
Конфиг уже в `firebase-config.js`. Данные этого сайта лежат ТОЛЬКО по пути `tdx-draft/main`,
поэтому прежние данные вашего другого проекта в этой базе чистить не нужно.

Откройте Firebase Console → проект `tdx-draft` → Realtime Database → вкладка **Rules** и **добавьте**
блок `tdx-draft` внутрь существующих `rules` (остальное не удаляйте):

```json
{
  "rules": {
    "tdx-draft": { ".read": true, ".write": true }
  }
}
```
(готовый пример — `database.rules.json`). Нажмите **Publish**.
Если вы раньше ограничивали базу по домену, добавьте `bogdan-ob.github.io` в Authentication → Settings → Authorized domains
и, если ключ ограничен, в Google Cloud Console → Credentials → HTTP referrers.

Это бесплатный план Spark. Правила открытые: любой, кто знает адрес базы, может писать в `tdx-draft`.
Для игры с друзьями этого достаточно; для публичного сайта нужна авторизация.

## Режимы
Переключатель в шапке (режим общий для обоих игроков, прогресс каждого режима сохраняется отдельно).
- **Wheel Draft** — колесо, 10 башен каждому, «подлянка», колода из 6. Кнопка **«EDJ бесплатна»** в верхней полосе (общая для обоих, до первого вращения): тогда крутят 9 раз, а EDJ сразу лежит в пуле.
- **Auction Draft** — 10 лотов, бюджет $20, максимум 5 башен, EDJ бесплатна у обоих. Колода (EDJ + 5 выигранных) готова сразу, выбирать ничего не нужно. Ставки, цена и «забирание» башни анимированы цветом команды. Подробные правила — на экране перед стартом.
  Если у одного игрока уже 5 башен, остальные лоты достаются сопернику бесплатно автоматически.

## Как играть (Wheel Draft)
Оба игрока открывают сайт, один занимает Blue, другой Red. Каждый крутит своё колесо 10 раз, затем решает
по «подлянке» и собирает колоду из 6 башен. Когда оба подтвердили, драфт завершён.
«Сбросить драфт» очищает всё. Если комната «зависла», смените `FIREBASE_ROOT` в `firebase-config.js`.

## Иконки башен
На своём компьютере запустите `python fetch-icons.py` из папки проекта — скрипт скачает иконки в `icons/`
и обновит `icons/index.json`. Затем загрузите папку `icons/` в репозиторий. Без иконок сайт показывает цветные бейджи.

## Где что менять
- `towers.js` — список башен и статусы (`pvp` / `banned` / `event`).
- `wheel-logic.js` — параметры колеса: `SLOTS`, `SPIN_MS`, `BASE_STEPS`, `FAST_SHARE`, `FAST_DECAY` (кривая скорости).
- `app.js` — Wheel Draft (`CFG`), интерфейс, отрисовка колеса, переключение режимов.
- `auction.js` — Auction Draft: настройки `AUCTION` (бюджет, число лотов, лимит башен), правила лота, интерфейс.
- `net.js` — слой Firebase. `style.css` — стили по разделам.


## Заметки
- MLRS — Event-башня, в драфт не попадает.
- Список башен — `towers.js` (статус `pvp` участвует, остальные нет). Допишите недостающие Gold/Crystal башни там.
- Открытие `index.html` двойным кликом или с localhost включает локальный режим (обе команды в одной вкладке); на GitHub Pages работает Firebase.
